
# Zuno API

API oficial da plataforma Zuno, construída com NestJS, Prisma e PostgreSQL.

## Visão geral

A Zuno API é responsável por gerir os principais fluxos da plataforma, incluindo:

- autenticação com access token e refresh token
- gestão de utilizadores
- categorias
- equipamentos
- reservas
- pagamentos
- disputas
